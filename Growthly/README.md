# Welcome to Growthly Mobile Application 👋

A FullStack peer-to-peer lending application created by Amanda Gurney, Taylor Martin and Ethan Sylvester.

### Description:

Growthly is a full-stack peer-to-peer lending platform that connects borrowers and lenders by matching them based on their financial needs. Our primary goal is to eliminate predatory lending practices that often exploit families and individuals from low to middle-income households. We achieve this by removing common barriers such as processing fees and offering fair, low-interest loans to ensure borrowers have access to affordable financial solutions.

---

### Install the EXPO GO App:

Locate the app store on your mobile device. Search for the 'Expo Go' application. You don't need to create an account to open Growthly.

---

### Installation Instructions:

1. **Clone Growthly-Mobile-Frontend Repository**  
Clone the repository to your local machine by running the following command:

```bash
git clone https://github.com/taylormarz/Growthly-Mobile-Frontend.git
```


2. **Navigate to New Local Repo**
After cloning the repo, navigate into the project directory:
```bash
cd Growthly-Mobile-Frontend
```

3. **Open Project is VS Code**
```bash
code .
```

4. **Open Terminal**  
ctrl+~

5. **Navigate into Growthly Directory**
```bash
cd Growthly
```

6. **Start Project**
```bash
npm start
```

6. **Open with Expo Go**  
Open the camera on your phone and scan the QR code that is generated in the terminal. This will open the 'Expo Go' app on your phone. You will be asked about accepting a network, accept it. The app will then open.
