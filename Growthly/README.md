# Welcome to Growthly Mobile Application 👋

A FullStack peer-to-peer lending application created by Amanda Gurney, Taylor Martin and Ethan Sylvester.

### Description

Growthly is a full-stack peer-to-peer lending platform that connects borrowers and lenders by matching them based on their financial needs. Our primary goal is to eliminate predatory lending practices that often exploit families and individuals from low to middle-income households. We achieve this by removing common barriers such as processing fees and offering fair, low-interest loans to ensure borrowers have access to affordable financial solutions.
